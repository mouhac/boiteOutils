Compagnon

Le seul outil de l'atelier qui ne tourne pas dans le navigateur.

Une page web n'a pas le droit d'aller chercher un fichier hébergé sur un autre site : c'est une règle de sécurité du navigateur, et elle ne se contourne pas. Le téléchargement en masse passe donc par un petit script Python à lancer sur votre machine.

Mise en route

Aucune installation : le script n'utilise que ce que Python fournit d'origine. Ouvrez un terminal dans le dossier compagnon/ et lancez : 

# voir toutes les commandes
python filet.py --help
Sous Windows — si python n'est pas reconnu, essayez py filet.py --help, ou installez Python depuis le Microsoft Store en cochant « Ajouter Python au PATH ».

Télécharger le Coran

La commande la plus simple récupère les 114 sourates récitées par Al-Hussary, nommées proprement, dans un dossier Coran/ : 

python filet.py coran

Vous obtenez 001 - Al-Fatiha.mp3, 002 - Al-Baqara.mp3, et ainsi de suite jusqu'à 114 - An-Nas.mp3. Comptez environ 800 Mo et une bonne heure sur une connexion ordinaire.

Verset par verset

6 236 fichiers, rangés dans un sous-dossier par sourate. Idéal pour apprendre : 

python filet.py coran --mode verset

Une sélection seulement

# le dernier juz, verset par verset
python filet.py coran --mode verset --sourates 78-114

# quelques sourates précises
python filet.py coran --sourates 1,36,55,67,112-114

Une autre récitation

# la liste complète
python filet.py coran --lister

# la lecture Warsh d'Al-Hussary
python filet.py coran -r hussary-warsh

Si la connexion coupe — relancez exactement la même commande. Tout ce qui est déjà téléchargé est sauté, et un fichier interrompu reprend là où il s'était arrêté. Les fichiers incomplets portent l'extension .part et ne sont jamais confondus avec les bons.

Explorer un site — le scraping

C'est le cœur de l'outil. On lui donne une adresse ; il fouille la page, dresse l'inventaire de tous les audios qu'il trouve avec leur poids, puis vous laisse tout prendre ou choisir. 

python filet.py page https://exemple.com/recitations

Ce qui s'affiche :

  1254 audios trouvés
  ───────────────────
     1  001 - Al-Fatiha.mp3                            913 Ko
     2  002 - Al-Baqara.mp3                             78 Mo
     3  003 - Al-Imran.mp3                              44 Mo
        …

  Poids au total : 4.2 Go

  Que voulez-vous faire ?

    1,5,10-20  télécharger cette sélection
    l          revoir la liste complète
    m          enregistrer la liste dans un fichier
    q          quitter sans rien télécharger

Vous tapez Entrée pour tout prendre, ou 3,7,20-45 pour une sélection. Le volume n'a pas d'importance : le script prend son temps, et une coupure de connexion ne coûte rien puisque tout est reprenable.

Où il va chercher

Beaucoup de sites n'écrivent aucune adresse de fichier dans leur page : ils chargent une playlist en JavaScript. C'est le cas d'Assabile. Le script lit donc, en plus du HTML :

  • les balises <audio> et <source> ;
  • les liens directs vers un fichier, en gardant le texte du lien comme nom — bien plus lisible qu'une adresse ;
  • tous les attributs data-* où se cachent les lecteurs ;
  • les adresses écrites en dur dans le JavaScript, même échappées ;
  • les playlists XSPF, M3U, JSON et les flux RSS de podcast, qui livrent souvent le catalogue entier d'un coup, titres compris.

Aller plus loin dans le site

# suivre les liens sur 2 niveaux (index → pages de sourates)
python filet.py page https://exemple.com -p 2

# en ne suivant que les pages qui nous intéressent
python filet.py page https://exemple.com -p 2 --filtre "sourate|surah"

# vérifier aussi les liens sans extension : /download/1234
python filet.py page https://exemple.com --fouiller
Un site qui propose dix versions du même titre ? --dedoublonner n'en garde qu'une par titre — la plus lourde, donc la mieux encodée. Sur la page d'Al-Hussary chez Assabile, cela ramène 1254 fichiers à une centaine.

Trier avant de télécharger

OptionEffet
--montrerdresser l'inventaire sans rien télécharger
--filtre-nomne garder que les noms contenant un motif
--min-mo Nécarter les fichiers de moins de N Mo (jingles, bips)

--tout-voirafficher l'inventaire complet sans le tronquer

Reprendre un inventaire plus tard

Depuis le menu, la touche m enregistre la liste trouvée dans un fichier liste-filet.json. On peut y revenir n'importe quand, sans refaire l'exploration : 

python filet.py liste Telechargements/liste-filet.json

Si le script ne trouve toujours rien, c'est que les liens n'existent qu'une fois la page ouverte dans un vrai navigateur. Dans ce cas, passez par la commande suivante.

YouTube et le reste

Pour tout ce qui résiste, filet passe la main à yt-dlp, qui connaît des milliers de sites : 

# une seule fois
pip install yt-dlp

# une playlist entière, en MP3
python filet.py video "https://youtube.com/playlist?list=…" --audio

# une vidéo, en meilleure qualité
python filet.py video "https://youtu.be/xxxxxxxx"

Réglages utiles

OptionEffet
-d DOSSIERoù ranger les fichiers
-f Ntéléchargements simultanés — 4 par défaut, montez à 8 en fibre, descendez à 2 sur une connexion capricieuse
-yne pas demander confirmation
--gabaritpointer vers une autre source, ex. "https://exemple.com/{n:03d}.mp3"
Si une source ne répond plus — les hébergeurs de récitations changent parfois d'adresse. Le script teste la source avant de se lancer et vous prévient tout de suite, plutôt que d'accumuler des milliers d'échecs. Vous pouvez alors indiquer la nouvelle adresse avec --gabarit.

Et après

Une fois les fichiers sur votre disque, le reste de l'atelier prend le relais : Alambic pour changer de format ou alléger les fichiers, Sillon pour extraire le son d'une vidéo téléchargée.
